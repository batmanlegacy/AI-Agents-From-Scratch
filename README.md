# AI-Agents-From-Scratch
Practical AI Agents for Real World tasks using LangChain, Groq, Gemini, and Structured Outputs.



🚀 A collection of practical AI Agents built for Real World tasks.

This repository documents my journey of building production-style AI agents using LangChain, Groq, Gemini, Structured Outputs, Pydantic, and Prompt Engineering.

---

## Why This Repository?

Most AI tutorials focus on generic chatbots and toy examples.

This repository focuses on real-world use cases relevant to:


- Real World Exmaples
- Research & Strategy

The objective is to build AI agents that can automate repetitive analytical tasks and improve decision-making workflows.

## Projects

### 1. Review Analyst Agent
Analyze customer reviews and generate:
- Sentiment
- Key Positives
- Key Negatives
- Customer Emotions
- Suggested Response

### 2. Product Analyst Agent
Convert raw product information into:
- Product Factsheets
- Product Summaries
- Strengths & Weaknesses
- Customer Recommendations

### 3. Research Paper Analyst
Extract:
- Research Objective
- Methodology
- Key Findings
- Limitations
- Future Scope
- Executive Summary

### 4. IT Support Agent
Automatically:
- Detect Language
- Translate Requests
- Categorize Issues
- Generate Customer Responses
